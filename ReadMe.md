# Kolla – Backend (C#)

## Zweck
Dieses Repository enthält das Backend (C#) für den Prototyp „Kolla“ aus dem Modul „Softwarearchitekturen und Qualitätssicherung (SAQS)“ (TH Brandenburg).   
Die Backend‑Implementierung ist prototypisch (Anwendungslogik kann simuliert sein) und dient primär dem Test der Schnittstellen und der Architekturentscheidungen, nicht dem Produktivbetrieb. 

## Projektkontext (SAQS)
Im SAQS‑Projekt wird eine Architektur für Kolla entworfen und anhand eines Prototyps validiert, insbesondere für die Zusammenarbeit zwischen GUI und Anwendungsebene.   
Persistenz ist im Architekturentwurf zu berücksichtigen, muss aber im Prototyp nicht zwingend vollständig umgesetzt sein. 

## Start (lokal)
- *dotnet* muss installiert sein
- Starten (im Projektverzeichnis): `dotnet run`
